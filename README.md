# E-Commerce Sales and Inventory Tracker

## Project Overview
A Tableau dashboard project for analyzing retail sales, revenue trends, product categories, and recorded inventory levels.

## Objectives
- Analyze monthly revenue trends.
- Compare units sold across categories.
- Examine recorded inventory by category.
- Identify the top 10 products by recorded inventory.

## Tools Used
- Tableau Desktop
- CSV dataset
- Data visualization

## Dashboard Charts
1. Monthly Revenue Trend
2. Inventory by Category
3. Units Sold by Category
4. Top 10 Products by Recorded Inventory

## Key Findings
- Groceries recorded the highest units sold: 3,127,335.
- Groceries recorded the highest total revenue: 168,864,432.
- Groceries had the highest summed recorded inventory level: 10,953,569.

*Inventory totals represent summed observations across the dataset, not necessarily current stock on hand.*

## Conclusion
This project demonstrates how data visualization can help businesses explore sales performance and inventory patterns to support planning and decision-making.</
